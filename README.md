# Blog — Sycetec · Monitoreo IoT

Versión pulida del blog académico para el proyecto de Formulación de Proyectos TI (UNTELS, 2026).

## Qué cambió

- Se eliminó la idea de tratar “elaboración progresiva” como uno de tres componentes de la definición de proyecto.
- Se reforzó la separación entre información verificada, referencial, simulada y pendiente.
- Se añadió un enfoque híbrido propuesto y un roadmap condicionado a la validación con Sycetec.
- Se limpiaron nombres y comentarios heredados de versiones anteriores del sitio.

## Páginas

- `index.html` — introducción, contexto del caso y enfoque metodológico y entrega de valor
- `que-es-un-proyecto.html` — proyecto, resultado, beneficio y valor
- `interesados.html` — dominio de interesados
- `principios.html` — 12 principios aplicados
- `dominios.html` — 8 dominios de desempeño

## Publicación

El sitio es estático. Puede desplegarse en Vercel, Netlify, GitHub Pages o cualquier servidor de archivos estáticos. Mantener la estructura de carpetas tal como está.
